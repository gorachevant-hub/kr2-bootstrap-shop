# Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание
Проект представляет собой учебную версию сайта интернет-магазина, разработанную с использованием Bootstrap.

## Используемый фреймворк
Bootstrap 5.3.x

## Способ подключения
Bootstrap подключён **локально**. Файлы фреймворка размещены в папке `vendor/bootstrap/`.

Используются:
- `vendor/bootstrap/css/bootstrap.min.css`;
- `vendor/bootstrap/js/bootstrap.bundle.min.js`.

CDN не используется.

## Структура проекта
- `index.html` – главная страница;
- `catalog.html` – каталог товаров;
- `product.html` – страница товара;
- `order.html` – форма заявки;
- `css/custom.css` – дополнительные стили проекта;
- `vendor/bootstrap/` – локальные файлы Bootstrap CSS и JS;
- `README.md` – описание проекта.

## Реализованные компоненты
- `navbar`;
- `card`;
- `btn`;
- `badge`;
- `alert`;
- `modal`;
- `form-control`;
- `form-select`;
- `input-group`;
- `form-check`;
- `accordion`;
- Сетка (`container`, `row`, `col-*`, `g-*`).

## Самостоятельные доработки
1. Bootstrap подключён локально (без CDN), файлы размещены в `vendor/bootstrap/`.
2. Создана страница товара с подробным описанием, таблицей характеристик и аккордеоном.
3. Добавлен дополнительный компонент `accordion` для раздела «Частые вопросы».
4. Формы адаптированы под мобильные экраны через `col-md-6`.
5. Добавлен файл `css/custom.css` для аккуратной стилизации блоков и заглушек изображений.
